A modern, luxury advocate portfolio website designed with an elite international legal aesthetic. Built with deep royal navy, obsidian black, ivory white, and antique brushed gold accents, combining high-end jurisprudence presentation with modern web performance.

## 🏛️ Highlights & Features

- **Luxury Aesthetic**: Styled like a premier international law firm or Supreme Court barrister's personal website.
- **Hero Showcase**: High-impact opening with custom-framed advocate portrait, credentials crest, and core ethos: *"Justice Is Not Just a Profession. It's a Responsibility."*
- **Curated Sections**:
  1. **About Advocate**: Core legal philosophy, people-centric policy advocacy, and credentials summary.
  2. **Education Timeline**: Vertical progression covering LL.M., LL.B. (Kurukshetra University), and B.Sc. (MDU Rohtak).
  3. **Achievements & Global Conclaves**: UN SDG Youth Action Youth Ambassador, BRICS Youth Energy Summit 2019, International Youth Council, and Panjab University Human Rights Conclave.
  4. **Skills & Legal Competencies**: 7-part grid showcasing public policy, legal research, advocacy, and debate.
  5. **Professional Philosophy**: Elegant quote section with Lady Justice watermark.
  6. **Writing & Interests**: Interdisciplinary pursuits and forthcoming legal publications.
  7. **Chamber Contact**: Direct call, email, and interactive legal consultation form with validation and toast alert.
- **Bar Council Compliance**: Integrated disclaimer adhering to Bar Council of India standards on non-solicitation.
- **Technical Excellence**: Zero dependencies, 100% semantic HTML5, modern CSS3 (Flexbox/Grid, Glassmorphism, CSS variables), and vanilla JavaScript.

## 🚀 Running Locally

Open directly in your web browser or run with any local HTTP server:

```bash
# 1. Navigate to the project directory
cd advocate-portfolio

# 2. Run with Python HTTP server
python3 -m http.server 4000

# 3. Open in browser:
open http://localhost:4000
```

## 🌐 Deploy to Vercel

This repository is pre-configured with `vercel.json` for one-click deployment:

1. Push this directory to your GitHub account.
2. In the [Vercel Dashboard](https://vercel.com), click **Add New Project** and select this repository.
3. Keep default settings (Static Site) and click **Deploy**.
